# French Real Estate Intelligence

End-to-end data science project for analysing, modelling and detecting
anomalies in the French residential real-estate market.

## Main objectives

- Build a reproducible DVF data pipeline
- Analyse price, liquidity and market dynamics
- Estimate the fair value of an apartment
- Detect statistically unusual transactions
- Segment geographical areas with clustering
- Build an interactive Streamlit application

## Current scope

First prototype: apartments in Lyon and Villeurbanne.
